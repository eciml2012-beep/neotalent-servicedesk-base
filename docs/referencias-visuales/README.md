# Referencias visuales

Fuentes que recomendó Alessandro en la Sesión 3 (22/09/2026, diapositiva 21) para buscar referencias antes de pedir cualquier diseño. Se usan en la Fase 2 (diseño).

Regla: nunca se pide un diseño sin enseñar antes una referencia.

| Sitio | Enlace | Para qué sirve en el Mini Service Desk |
|---|---|---|
| Dribbble | https://dribbble.com | Pantallas de trabajo. Buscar "helpdesk dashboard", "ticket inbox" o "admin table". |
| Bento Grids | https://bentogrids.com | Organizar en bloques la cabecera de KPIs: tickets por prioridad, pendientes de confirmar. |
| Pinterest | https://es.pinterest.com | Juntar en un tablero lo que guste de cualquier sitio. |
| Awwwards | https://awwwards.com | Webs premiadas. Sobre todo sitios de marketing; menos útil para una herramienta interna. |
| Land-book | https://land-book.com | Galería de landing pages. Menos útil aquí. |
| MotionSites | https://motionsites.xyz | Webs con animación. Menos útil para una herramienta de uso diario. |
